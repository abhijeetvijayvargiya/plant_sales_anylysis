# 🌿 Plant Sales Analysis

## 📌 Project Overview

This project analyzes a plant sales dataset to uncover pricing patterns, customer preferences, and factors affecting product returns. The analysis focuses on discounts, ratings, plant sizes, brands, and locations to generate actionable business insights.

---

## 🎯 Objective

The main objectives of this project are to:

- Analyze plant pricing and discount strategies.
- Compare Original Price and Special Price.
- Identify high-performing plant brands.
- Evaluate customer ratings across different plant types.
- Analyze return trends.
- Understand the impact of location and plant size on sales performance.
- Generate business insights through data visualization.

---

## 📂 Dataset

The dataset contains the following columns:

| Column | Description |
|---------|-------------|
| Original Price | Actual listed price of the plant |
| Special Price | Discounted selling price |
| Discount | Discount offered on the product |
| Rating | Customer rating |
| Plant Size | Size of the plant (Small, Medium, Large) |
| Type | Category/Type of plant |
| Location | Selling location or warehouse |
| Brand Name | Plant brand |
| Return | Return status of the product |
